# Lavipronto S.A.C. — Sitio web

Sitio estático (HTML, CSS y JS). No necesita instalación.

## Publicar en GitHub Pages
1. Crea un repositorio nuevo (por ejemplo `lavipronto`).
2. Sube todo el contenido de esta carpeta a la raíz del repositorio.
3. En GitHub: Settings → Pages → Source: "Deploy from a branch" → Branch: `main` / `(root)` → Save.
4. En un par de minutos el sitio queda en `https://TU-USUARIO.github.io/lavipronto/`.

## Personalizar
- **Logo:** guarda el logo real como `assets/logo.png` (se usa automáticamente; si no existe, se muestra `assets/logo.svg`).
- **Foto del local:** guarda una foto como `assets/img/local.jpg` y aparece en la sección "Nosotros".
- **Colores:** edita las variables al inicio de `css/styles.css`.
- **WhatsApp:** número `51965389994` en `index.html` y en `js/main.js`.
