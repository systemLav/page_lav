# Lavandería Lavipronto S.A.C. — Sitio web

Sitio estático (HTML, CSS y JS). No necesita instalación.

## Publicar en GitHub Pages
1. Sube el CONTENIDO de esta carpeta a la raíz del repositorio (index.html debe quedar en la raíz).
2. Settings → Pages → Deploy from a branch → `main` / `(root)` → Save.

## Personalizar
- **Colores:** variables al inicio de `css/styles.css` (tomados del logo).
- **Fotos:** carpeta `assets/img/`. Reemplaza una foto usando el mismo nombre de archivo.
- **Logo:** `assets/logo.png`.
- **WhatsApp:** número `51965389994` en `index.html` y `js/main.js`.
